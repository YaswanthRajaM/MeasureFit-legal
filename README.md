# ProgressPic — Legal

Public legal documents for the **ProgressPic** iOS app.

- [Privacy Policy](./privacy.md)
- [Terms of Use](./terms.md)

These URLs are referenced from the App Store listing and from inside the app.

## Hosting

This folder is intended to be served as a public GitHub Pages site so the documents are reachable from publicly-accessible URLs (required by Apple).

After enabling GitHub Pages on the hosting repo, the URLs typically look like:

- `https://<user>.github.io/<repo>/privacy`
- `https://<user>.github.io/<repo>/terms`

Update the App Store Connect listing and the in-app "Privacy Policy" / "Terms of Use" links to point at these URLs.

## Updating

1. Edit `privacy.md` or `terms.md`.
2. Bump the **Last updated** date at the top of the document.
3. Commit and push — GitHub Pages republishes automatically.
4. For material changes, surface a notice inside the app on next launch.
